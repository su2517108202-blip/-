# Taste 设计参考

Taste 适合比较整页的排版、摄影和滚动节奏，也能补上主参考未展示的区段与交互。先从本项目要解决的问题选示例，例如照片与大标题如何同框，首屏怎样接进作品，或浏览者怎样看清同一项目的更多细节。 [Taste 整站案例](https://github.com/Leonxlnx/taste-skill/tree/f6b76575f949707b4e3c37cd86cb44b0b98643e8/examples/v2)

## 按要解决的问题选入口

| 要解决的问题 | 看哪个示例 |
| --- | --- |

先运行入选示例，观察主体、文字与动作如何衔接。使用共享 `frontend-design` 时，通过其可运行资源手册按名字提取原版文件。例如用 `stage moment/photo-chapters` 取出滚动叙事示例和依赖。把同一处关系用本项目的照片、标题和内容做出来，再从上一个区段滚到下一处或进入详情核对。

示例固定到共享技能所用的上游版本。Taste 源码采用 MIT 许可，示例图片的使用条件以各自的署名记录为准。 [固定版本](https://github.com/Leonxlnx/taste-skill/commit/f6b76575f949707b4e3c37cd86cb44b0b98643e8) · [MIT 许可](https://github.com/Leonxlnx/taste-skill/blob/f6b76575f949707b4e3c37cd86cb44b0b98643e8/LICENSE)
