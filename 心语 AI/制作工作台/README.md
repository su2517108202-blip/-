# 心语 AI 制作工作台

直接打开 `index.html`。默认在「资产」，可切换「旧码头」和「晨雾中的渡口」，核对中间原图与整窗底图是否同时切换。点中央原图打开原画幅，按 Esc 关闭。五步使用合成的「归港」故事、场景和片段，以便离线复验布局。

版式沿用心形工作台原定稿的作品舞台、目录与右栏。原定稿的舞台插画扩展为整窗底图，选中资产时用当前原图作为半透背景。原图在中间保留画幅，右栏留给规格和操作。窄窗依次排列舞台、目录和详情。阅读面用浅色纸面承载正文或镜头。

`heart-stage.css` 来自源码版 `web/src/styles/heart-stage.css`。可运行样例给出布局接入需要的 HTML 结构和基础样式。实际应用的 `web/src/production/index.js` 渲染项目栏和五步，`heart-stage.js` 维护作品目录、聚焦、背景和原画入口，`heart-stage-entries.js` 从当前项目及归档版本读取作品。样例中的图片由浏览器绘制。

在实际应用复验时，从项目库进入有参考图的项目，依次打开资产、原画幅和资产编辑。关闭返回同一条资产，再切到分镜检查片段定位，用窄窗复验画幅和控件。样例可用于核对框架的构图与换图，生产保存与播放由原宿主驱动。

中央工作面由预览、单行操作和正文或提示词组成，两侧使用等宽布局。原应用的五步伙伴、心形聚拢、打散和环绕继续由 `heart-stage.js` 与 `character-motion.js` 驱动。此离线样例用于核对版式、换图和原画幅。

资产示例右栏的「编辑资产」将中央图片提示词原位切换为输入框。「完成编辑」回到该条目的阅读状态，修改仅保存在示例运行期间。真实应用在同一路径提供导入、参考图、规格、设定与历史。

`shell.html` 演示外围应用外壳。打开后可切换项目目录、搜索，并从「归港」进入制作样例。共用的 `studio-frame.css` 来自源码的同名文件，定义居中导航、页面间距和弹窗结构。实际应用中，外壳由 `web/src/layout/studio-shell.js` 渲染，二级页分别由 `pages`、`canvas` 和 `themes` 下的入口渲染，共用弹窗从 `application/src/core/ui.js` 挂载。
